# mora_wechat

Mora 学习卡片微信小程序。

- **AppID**: `wxf251bca64dd09232`
- **远程仓库**: `git@github.com:Broccoli-X/mora_wechat.git`

## 开发

1. 克隆本仓库
2. 使用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 导入项目根目录（AppID 会自动从 `project.config.json` 读取）
3. 编译即可在模拟器预览

## 注意事项

- 全部 `/api/` 数据接口已启用家长密码鉴权（与 mora 网页端同协议）：首次使用在登录页输入家长密码（可填家庭ID）换长期会话 token（服务端滑动 180 天过期），本设备登录一次长期有效；会话失效收到 401 会自动清 token 弹回登录页。换家庭登录会清掉上一家的本地缓存防串数据，「我的」页可查看当前家庭并退出登录。
- 作业数据来自 mora 项目的进度同步服务（`https://www.tcued.com/api/progress`），录入/删除在网页端维护，小程序端可查看与勾选完成：条目 `done` 标记随 payload 短键 `c` 同步（与网页端 `lib/homework-core.js` 同协议，未完成不产生 `c` 键兼容旧数据），切换完成走单条上报、payload 始终带全图片引用（服务端会清理不再被引用的图片）。
- 「我的 → 家长维护 → 作业」为小程序端登记页（`pages/hw-edit`，与网页端 `zuoye-edit.html` 同协议）：日期不限未来，可提前登记明天以后的作业（网页端日期输入同样没有上限）；存完停在所选日期，方便连着录几科；‹ › 一天一天翻天，日期旁「今天/明天/后天」胶囊作锚点（用户明示不做「回到今天」按钮，回今天走日期选择器）。
- 作业图片存于同一服务：payload 内是图片 id（短键 `g`），本体经 `GET /api/image?id=<id>` 读取（不带 token，与网页端一致）；作业本页点缩略图可全屏预览。
- 拼音学习卡数据与 mora 网页端 `lib/pinyin-data.js` 同源；卡片为纯视觉学习卡（不带发音）。
- 拼音掌握进度多端共享：与 mora 网页端（`pinyin-flashcards.html`/`report.html`）走同一服务（`/api/progress`，module=`pinyin`），协议同 `lib/progress-sync.js`——本地存储为第一写入点，进页面拉取合并、点标记异步上报，同键位 `updatedAt` 新者胜；离线时纯本地，联网后自动补传。键位/存储键与网页端一致。
- 上线前需在小程序管理后台把 `https://www.tcued.com` 配置为 request 合法域名；开发阶段可在开发者工具里勾选「不校验合法域名」调试。
- 识记学习（分类页「综合 → 识记」）读的是 mora 网页端「识记练习录入」（`recognition-edit.html`）里家长按次录入的批次内容，两步接口取用（与网页端 `server/README.md`「六」同协议）：先 `GET /api/recognition/batches` 拿批次列表（**只有概要**：名称/日期/条数/备注/首条预览），再 `GET /api/recognition/batch?id=<批次id>` 按批次取整批条目；批次与整批内容都进本机缓存，离线可看已拉过的内容。识图的图片是条目里的 `img` id，本体经 `GET /api/image?id=<img>` 读取（不带 token）。
- 识记条目形状随网页端（识汉字＝单字+拼音；**学英语**＝单词或整句，大小写照原样，如 `Good morning, Miss Li.`；识图＝图片或 emoji+名称；**学文章**＝一段原文 `{text}`，一行一段拆开或整篇存一条带换行，没有答案栏，批次带 `lang` zh/en、标题可不填）。小程序端**只做渲染保护（长度截断）不复刻服务端字面校验**：网页端规则一变（2026-09-11「认单词支持整句」，该科 2026-09-14 改名叫「学英语」）复刻版就会静默吃掉条目（曾 11 条只显示 6 条），内容以服务端为真源。
- 识记四科的显示名与网页端一致（识汉字 / 学英语 / 识图 / 学文章；`words` 只是 id，改名不动历史批次与接口口径）。学文章批次无标题时显示名取首条原文开头前 12 字加省略号（列表用服务端概要的 `preview` 首条预览兜底，与网页端 `displayName` 同口径），再没有叫「未命名」。
- 识记学习不带 ⭐ 掌握标记：网页端口径「本站不出题、不记成绩」，进度同步服务端白名单（`MODULES`）也不含 `recognition`，故小程序端只做认读浏览，禅模式只显示当前序号。功能权限键为 `recognition`（与网页端 `FEATURES` 同名），未开通家庭入口不呈现、深链整页拦截。
- 识记禅模式里**学英语 / 识图正面只给主体**（词句 / 图片），点卡片 3D 翻面才显示意思（中文 / 名称 + 音标 / 英文），小朋友在正面看不到任何提示；识汉字不翻面（汉字 + 拼音 + 组词一屏给全）；学文章也不翻面（无答案栏，全文即正面），字号按原文长度分档（≤40 字大 / ≤150 字中 / 其余小），小档整篇卡内上下滚动、左右滑仍是换段。轻点翻面、滑动换卡，换卡后新卡一律从正面起。批次页网格列数随学科：识汉字 3 列 / 学英语·识图 2 列 / 学文章 1 列宽卡（「第 N 段」标 + 两行预览）；批次头部学文章多一枚语种胶囊（语文/英语），计数单位按「条/段」区分。
- 禅模式换卡为**批次内顺序上一张/下一张**（首尾循环），动效与字母卡禅模式同款（方向感知出/入 + 奇偶异名强制重放 + 轻震动）；字母卡是随机抽认，两者语义不同、动效一致。
- 知识点总结（分类页「语文 → 知识点总结」）读的是 mora 网页端「知识点录入」（`knowledge-edit.html`，仅管理员维护）按教材（年级+科目+册）整理的单元必背知识，两步接口取用（与网页端 `server/README.md`「七」同协议）：先 `GET /api/knowledge` 拿书目列表，再 `GET /api/knowledge/book?grade&subject&volume` 按教材取整本 `units` 全文；书目与整本都进本机缓存，离线可看已拉过的教材。页面流：书目列表 → 单元列表（单元配色与网页端 `UCOLORS` 同表轮换）→ 点单元进禅模式，单元内**每个知识块一张卡**、左右滑动逐项背（首尾循环，动效同识记禅模式；知识块是读背内容，没有正反面、不翻面）。
- 知识点正文按网页端 `knowledge.html` 同规则渲染：① 着重号——注音标在哪个字上就用「」把那个字括起来（如 `下「棋」(qí)`），整词只有一个字 + 括号里是拼音时自动加点（前面紧挨汉字时不加，与网页 `pyDot` 同边界）；② 形近字——块小标题含「形近字」且行含 `↔` 的一行一组，上下两员配左侧大括号；③ 象形字配图——「字符数=图片数」（逐字一行，或单行按空白拆）时汉字作图注嵌进对应图卡、原文字行不再单出（网页端「逐字一行」分支曾有 `capRowIdx=-2` 过滤器永不命中、文字行展示两遍的 bug，2026-09-18 已修——mora `923ae12`；两端同规则，被用作图注的行不再单出）；「例：/仿写：」行淡化展示。配图是站内相对路径，拼在 `https://www.tcued.com/` 下直接当图片地址（不带 token）。
- 知识点接口的读取只验 token（服务端 `FEATURES` 无 knowledge 键、写入才限管理员家庭），故入口不挂功能键，家长登录即可看，与网页端 `knowledge.html` 同门槛。
