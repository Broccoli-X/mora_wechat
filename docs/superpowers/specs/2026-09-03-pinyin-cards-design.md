# 拼音学习卡（基础）设计

日期：2026-09-03
状态：已实现

## 需求

- 新增「拼音学习卡」功能，分为**拼音基础**与**拼音进阶**两部分。
- 进阶部分（拼音识字打卡、拼音识汉字）**本期不推进**，仅保留入口占位。
- 参考竞品「拼音智能点读」：基础部分含字母表/声母表/韵母表/整体认读/声调表五个入口，彩色大卡、点击学习。

## 数据来源

与 mora 网页端 `lib/pinyin-data.js` 同源（内容逐条一致，键位格式 `分类:拼音` 也一致）：

| 分组 | 键 | 数量 |
|---|---|---|
| 声母 | sm | 23 |
| 单韵母 | dy | 6 |
| 复韵母 | fy | 9 |
| 前鼻韵母 | qb | 5 |
| 后鼻韵母 | hb | 4 |
| 整体认读 | zt | 16 |
| 四声调 | sd | 4 |

小程序端聚合为四个学习表：**声母表(23)、韵母表(24)=dy+fy+qb+hb、整体认读(16)、声调表(4)**，共 67 张卡。每张卡 = [拼音, emoji, 例字/口诀, 例字拼音, 分组]。

## 页面

### 拼音主页 pages/pinyin/pinyin

- 「拼音基础」：四张彩色大卡（配色沿用网页端：声母蓝 #4A90E2、韵母玫红 #EF476F、整体认读紫 #AF52DE、声调青 #00B894）。布局仿竞品：声母表通栏、韵母表+整体认读双列、声调表通栏。每卡显示数量与该表已掌握进度。
- 「拼音进阶」：一张置灰占位卡「拼音识字打卡 · 敬请期待」，点击 toast 提示，结构上为后续 300 字识字卡留位。
- 头部显示总进度「共 67 张 · 已掌握 x 张」。

### 学习页 pages/pinyin/study?type=sm|ym|zt|sd

- 按传入类型渲染对应表格（韵母表内按 单韵母/复韵母/前鼻/后鼻 分小组标题；声调表为 4 条通栏卡：调号行 + 口诀 + 例「妈mā 麻má 马mǎ 骂mà」）。
- 卡片网格（3 列）：色块拼音大字 + emoji + 例字/例字拼音（单韵母显示口诀）。
- 纯视觉学习卡（无发音）；右上角**星星标记已掌握**，掌握状态金色描边高亮。
- 顶部进度「已掌握 x / n」，导航栏标题随表格切换。

## 掌握进度（多端同步）

- 本地存储为第一写入点：`mora-pinyin-mastered-v1`（键位数组）+ `mora-pinyin-mastered-ts-v1`（时间戳），键位 `分类:拼音` 与网页端一致。
- 与 mora 网页端（`pinyin-flashcards.html`/`report.html`）多端共享：协议同 `lib/progress-sync.js`，服务 `https://www.tcued.com/api/progress`（module=`pinyin`，token 鉴权）。
  - 进页面 `GET /api/progress` 拉全量 → 过滤本模块与合法键位 → 与本地按 `updatedAt` 新者胜合并（相等取本地）→ 落盘；本地比远端新（或远端没有）的条目补传。
  - 点 ☆ 标记/取消：先写本地，再 `POST` 单条 `{module,itemKey,mastered,updatedAt,device}`（fire-and-forget，失败静默，靠下次同步补传）。
  - 设备名 `平台-随机尾`（存储键 `mora-device`，首次生成后固定），与网页端 `deviceName()` 同语义。
- 请求失败全程静默降级为纯本地模式，不阻塞页面。
