# 首页设计：课程表 + 作业本查看

日期：2026-09-02
状态：已实现

## 目标

小程序首个可用版本：首页提供「课程表」和「作业本查看」两个功能。其余学习卡片功能（古诗/拼音/单词等）暂不纳入。

## 结构决策

课程表是 7×5 的宽表格、作业本需要按周导航，两者在手机上各自需要整屏空间，因此采用**首页入口卡片 + 两个功能子页**的结构，而不是把内容平铺在首页：

- `pages/index` 首页：沿用现有品牌 hero（M 徽标 + 标题），下方两张功能卡片，卡片带实时预览（课程表卡显示今天星期几和当前/下一节课；作业本卡显示今天日期和今日作业数），点击进入对应页面。
- `pages/kebiao` 课程表：星期页签（周一~周五，今天默认选中，周末默认周一并提示休息），节次列表展示科目色块 + 老师 + 备注，今天的当前节次高亮「现在」。比网页端的整周表格更适合手机阅读。
- `pages/zuoye` 作业本：与网页端 zuoye.html 一致的按周查看——上一周/下一周/回到本周，周一~周日每日卡片，今天高亮；数据只读（录入/删除在网页端 zuoye-edit.html 由家长维护），支持下拉刷新，同步失败显示重试。

## 数据来源

- **课程表**：静态数据，从 mora 网页端 `lib/kebiao-data.js` 同步为 `utils/kebiao.js`（换学期时两处一起改 grid）。配色/图标沿用 `KEBIAO_META`。
- **作业本**：与网页端同一个进度同步服务 `GET https://www.tcued.com/api/progress?token=<token>`，取 `module === 'homework'` 的条目，payload 短键 JSON `{d, s, t}` 解码；空 payload（删除墓碑）与坏 payload 跳过。逻辑封装在 `utils/homework.js`（日期工具与 mora 网页端 `lib/homework-core.js` 同源）。

## 错误处理

- 作业同步失败：首页卡片显示「同步失败，进入查看详情」；作业本页显示错误卡片 + 重试按钮，已加载内容不受影响（重试成功后重画）。
- 周末：课程表卡显示休息提示；课表页当前节次高亮自动关闭。
- 未知科目：灰色 📌 兜底色块，不报错。

## 上线注意

- 小程序管理后台需把 `https://www.tcued.com` 配置为 request 合法域名；开发阶段可在开发者工具勾选「不校验合法域名」。
