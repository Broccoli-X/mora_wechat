# 知识点总结（语文栏目）设计

日期：2026-09-18
状态：已实现

## 需求

- 网页端已新增「知识点总结」模块（`knowledge-edit.html` 仅管理员按教材维护、`knowledge.html` 展示，一上语文 7 个单元全文入库）。
- 小程序端在**分类页「语文」栏目**下新增同款「知识点总结」：书目列表 → 单元列表 → **点开具体单元用禅模式逐块展示背诵**。

## 数据来源与协议（两步接口）

与 mora 网页端 `server/README.md`「七、知识点总结接口」同协议：

- 第一步 `GET /api/knowledge?token=`
  → `{ok, books:[{grade,subject,volume,title,updatedAt}]}`（书目概要，标题从 data 里带出）
- 第二步 `GET /api/knowledge/book?token=&grade=&subject=&volume=`
  → `{ok, updatedAt, data:{title, units:[{name, sections:[{title, blocks:[{h, rows[, imgs]}]}]}]}}`
- 配图：`imgs` 是站内相对路径（如 `images/knowledge/ri.png`），拼在 `https://www.tcued.com/` 下直接当图片地址（不带 token，与作业/识图图片同域名白名单）。
- 空册：服务端返回 `{ok, data:null}`——与「拉取失败」分开文案。

### 权限：入口不挂功能键

服务端 `/api/knowledge*` 读取**只验 token**（`FEATURES` 白名单没有 knowledge 键），写入才限管理员家庭。故小程序入口不设 `perm`，家长登录即可看，与网页端 `knowledge.html` 同门槛（网页端也只有「录入」入口是管理员可见）。

### 客户端只做渲染保护

沿用识记模块 2026-09-11 事故后的决定（见 `2026-09-11-recognition-study-design.md`）：不复刻服务端 `valid_knowledge()` 的字面校验，只做「能不能渲染」保护——空行丢弃、长度截断（title 80 / 单元节名 40 / h 60 / 行 200、数量上限 30/20/40/80/20 与服务端同口径）、imgs 只收站内相对路径（`KNOWLEDGE_IMG` 同正则 + 拒 `..`）。块里行与图都没了才丢块。

## 展示规则（与网页端 knowledge.html 同款）

README 约定「小程序可按同样规则自行渲染，或原样展示」，本期按同规则渲染：

1. **着重号**：注音标在哪个字上就用「」把那个字括起来（如 `下「棋」(qí)`）→ 拆段渲染、该字下加红点（`.zc-zd::after` 圆点，PDF 同款）。整词只有一个字 + 括号里是拼音（含拉丁字母）时自动加点；**边界与网页 `pyDot` 一致**——该字前面紧挨汉字时不加（`三人(sān)` 的三不点，`你(nǐ)　三(sān)` 的三点）。已被「」消费过的字不重复加点。
2. **形近字**：块小标题含「形近字」且行含 `↔` 的一行一组 → 上下两员 + 左侧大括号（Georgia 细体）；块内无 ↔ 的行仍作普通行。小标题不含「形近字」的 ↔ 行（如反义词）不拆对。
3. **象形字配图**：「字符数=图片数」时汉字作图注嵌进对应图卡、原文字行不再单出——两种形态：逐字一行（行数=图数，全部行作图注）或单行按空白/全角空格拆开后个数相等（该行作图注）；配不上时图片与文字行各排各的。
   ⚠️ 网页端「逐字一行」分支用 `capRowIdx=-2` 让过滤器永不命中，文字行实际没被去掉，属潜伏 bug（与它自己的注释、提交 51720c5 的说明相悖）；现有数据只用单行形式故未显形。小程序按其**意图**实现（两分支都去掉被用作图注的行），网页端待修。
4. **例：/仿写：**打头的行淡化展示（灰色小字，与网页 `.row.example` 同款）。
5. **单元配色**：与网页端 `UCOLORS` 同表轮换（8 组主色/深色），单元列表卡头与禅模式点缀条/节名签/块标题取该单元色。

## 方案取舍

- **三页结构**：书目列表（`knowledge`）→ 单元列表（`book`）→ 禅模式（`zen`），与识记模块（列表→批次→禅）同构。书目与单元分两页是因为整本 units 较大（一上 7 单元 500+ 行数据），点开哪册再取哪册。
- **禅模式一卡=一个知识块**：块（小标题 + 几行）是天然的背诵单元，一上一单元约 10 块；比按行拆碎、按节合并（一节 8 块放不下）都合适。卡顶节名小签 + 块小标题，卡内超长就地滚动（`max-height:62vh + overflow-y:auto`），横滑换卡不受影响。
- **禅模式不翻面**：知识块是读背内容，没有「正面题目/背面答案」的藏与露，全部信息一屏给全；区别于识记禅模式（学英语/识图翻面看意思）。动效完全同款（方向感知出/入 + 奇偶异名强制重放 + 轻震动），`in/out × l/r × 奇偶` 8 类名各绑不同 `animation-name`（`knIn*`/`knOut*`），`tests/cards-css.test.js` 已补契约。
- **顺序换卡（首尾循环）**：单元是家长整理好的必背顺序，顺序背比随机抽合适（与识记禅模式同语义）。
- **取数交接**：单元页点单元时 `setCurrent` 把整本交给禅模式（免一次请求）；深链/重启回落本机缓存（按 `年级|科目|册` 键），再没有才拉远端。交接记下所属家庭，换家庭登录防串（与识记同一条红线）。缓存上限 10 册，超出按 `updatedAt` 淘汰最旧。
- 不做：⭐ 掌握标记（内容型浏览，进度白名单无关）、本地录入（写入仅限管理员，网页端维护）。

## 页面

### 书目列表 pages/knowledge/knowledge

- 登录门 `auth.ensure()`（无功能键）；顶部标题 + 「共 N 本教材」胶囊。
- 教材卡：标题（`一年级上册语文 · 单元必背知识`）+ 年级·科目·册元信息；点卡跳单元页（三键 URL 编码）。
- 空态引导家长去网页端「知识点录入」维护；失败无缓存给重试。下拉刷新。

### 单元列表 pages/knowledge/book?grade&subject&volume

- 头部书名 + 「共 N 个单元」；单元卡=色块头（单元名 + 「N 个板块 · M 项」白字胶囊）+ 白身「开始背诵 ›」。
- 点单元：`setCurrent` 交接 + 跳禅模式 `?grade&subject&volume&u=<下标>`。空册/失败分开文案；离线走缓存。下拉刷新。

### 禅模式 pages/knowledge/zen?grade&subject&volume&u

- 自绘导航：✕ 固定左上角（右上角是小程序胶囊，不能放）；顶部胶囊「单元名 · 书名 · 3 / 10」。
- 大白卡：点缀色条（单元主色）→ 节名小签 → 块小标题（单元深色）→ 正文（行/图/大括号三种形态见上）。
- 左右滑动换卡（左滑下一项、右滑上一项，首尾循环，轻震动）；轻点不翻面。单张不响应滑动。
- 配图加载失败就地置灰占位（🖼️），图注保留，不白屏。空册/单元不在给 gone 态。

## 入口

- 分类页「学科 → 语文」新增「知识点总结」（desc：单元必背知识 · 禅模式逐项背），不挂 `perm`。
