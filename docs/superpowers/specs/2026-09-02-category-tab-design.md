# 分类 tab 与首页「今日信息」改版设计

日期：2026-09-02
状态：已实现

## 需求

- 新增 tabBar：首页 + 分类两个 tab（当前首页保留为首页 tab）。
- 分类页按「学科」「综合」两组组织功能入口。
- 首页聚焦「今日相关信息」。

## 设计

### tabBar

- 首页 `pages/index/index`（选中色 #4f7cff，普通色 #9aa1b0）。
- 分类 `pages/category/category`。
- 图标为 `assets/tabbar/` 下脚本绘制的 81×81 透明 PNG（房子/四宫格 × 灰/蓝，见 `gen_tab_icons` 脚本思路：几何 SDF + 4× 超采样，node zlib 手写 PNG 编码），保证风格一致且颜色精确。

### 分类页 pages/category

数据驱动（页面内 `GROUPS` 常量），两级结构：

- **学科**：按科目分组（配色沿用课表科目色）——语文（古诗卡片/生字卡片/拼音练习）、数学（口算练习）、英语（自然拼读/单词卡片）。这些对应 mora 网页端已有模块，小程序端尚未开发，条目带「开发中」徽标，点击 toast 提示。
- **综合**：日常（课程表/作业本，均可用，直接跳转既有页面）。

后续开发某学科功能时，只需在 GROUPS 里把对应条目补上 `status: 'ok'` 与 `url`。

### 首页改版（今日信息）

原「两张入口大卡」改为信息版式，进入即读今天的事：

- 头部：品牌行（M 徽标 + 名称）+ 右侧醒目的「X月X日 · 星期X」。
- **今日课程**卡片：今天 7 节课的时间线（时间 + 科目色块 + 节次），当前节次橙色高亮「现在」；周末显示休息提示。右上「整周课表 ›」跳课程表页。
- **今日作业**卡片：今天的作业条目（科目色块 + 内容），同步失败显示重试；右上「全部作业 ›」跳作业本页。首页开启下拉刷新。
- `onShow` 时刷新两部分数据（从子页返回也能更新）。

## 迭代（同日第二次调整）

- **首页课程模块改为单条**：判定逻辑收进 `utils/kebiao.js` 的 `homeLesson(now)`——优先显示当前节；无当前节（课前/课间）显示今天接下来的节（徽标「下一节」）；今天课上完显示次日第 1 节（标题变「次日课程」，徽标为星期名）；次日无课（周末）整块隐藏。当前节保持橙色高亮。
- **分类页隐藏未开发条目**：`visibleGroups` 过滤只保留 `status:'ok'` 的条目，空科目/空组随之隐藏；数据定义原样保留，功能开发完成后改 `status` 补 `url` 即自动出现。当前实际只显示「综合 → 日常」下的课程表与作业本。
