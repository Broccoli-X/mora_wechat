# 识字卡片（汉字学习卡）设计

日期：2026-09-03
状态：已实现

## 需求

- 新增「识字卡片」：按主题分组认汉字，看拼音、注音分解，标记已掌握。
- 数据来源 mora 网页版识字模块（character-recognition.html），与网页端**共用同一份在线字库与掌握进度**。

## 方案取舍

- 数据：网页端字库**在线可维护**（hanzi-edit.html，整库存服务端 hanzi_meta），与拼音的静态数据不同。故不采用纯静态副本（会漂移），而与网页端 `lib/hanzi-store.js` 同协议：**打包种子兜底 + 本地缓存优先渲染 + 进页面拉 `/api/hanzi` 最新（updatedAt 更新才替换）**，离线/失败静默用本地。
- 掌握进度：与网页端完全共享，module=`chars`、itemKey=汉字本身（网页端 `MoraSync.pushOne("chars", c, ...)` 同款）。协议与小程序端 `utils/pinyin.js` 一致（GET 全量合并新者胜、POST 单条上报、失败静默）。
- 笔顺动画（hanzi-writer）：小程序 canvas 移植成本高，本期不做；也不打包 360KB char-data.js（沿用拼音卡"保持精简"的先例）。笔画**数**保留：种子 190 字笔数从网页端 char-data.js 提取打包（约 1.5KB，服务端 hanzi_strokes 只存在线新增字的笔画）；在线新增字进详情时懒取 `/api/hanzi-stroke` 仅取笔数（内容不可变，取到即永久缓存），失败不显示。
- 随机复习 / 考一考 / 最近新增 / 搜索：本期不做（备后续）。

## 数据

- 种子：`lib/hanzi-seed.js`（190 字 / 14 主题组）同步副本进 `utils/hanzi.js`。
  - groups：`[组键, 组名(含emoji), [字…]]`；chars：`[字, [全拼, 声母, 介母, 韵母], 多音字组词(可空), 组键]`。
- 远端：`GET /api/hanzi?token=` → `{ok, data:{groups,chars}, updatedAt}`（整库未初始化时 data=null）；`GET /api/hanzi-stroke?token=&c=字` → `{ok, data:{strokes:[…]}}`，404=无数据。
- 组色：14 个种子组用网页端固定配色（hanzi-core FIXED）；在线新建组键按哈希从同一调色盘确定性取色（移植 hanzi-core `gc()`）。
- 本地存储键：数据集 `mora-hanzi-dataset-v1`（{updatedAt,data}）、笔画数 `mora-hanzi-strokes-v1`（{字:笔数}）、掌握 `mora-hanzi-mastered-v1` + `mora-hanzi-mastered-ts-v1`、设备名复用 `mora-device`。
- 掌握键位合法性：按**当前生效字库**全字过滤（防脏数据落盘，与拼音一致）；库外字（如网页端新增但拉取失败时）不落盘，服务端仍有，待数据集更新后自然回归。

## 页面

### 主页 pages/hanzi/hanzi

- 头部总进度「共 N 字 · 已掌握 x 字」。
- 「全部汉字」通栏渐变大卡 + 14 张主题组双列卡（组色渐变、组名、字数、⭐ 已掌握 x/y）。
- onShow：本地缓存/种子即渲染 → `syncMastered` 合并进度 → `fetchDataset` 有更新则重建视图重渲染。

### 学习页 pages/hanzi/study?g=<组键>|__all

- 顶部进度卡（已掌握 x / n + 进度条），导航标题随组名。
- 按组分段：组名 pill（组色）+ 字卡网格（3 列）。卡面：色顶拼音 + ★（catchtap 标掌握）、大字（楷体优先）、底部小字多音字组词或组名。掌握卡金边高亮（与拼音学习页一致）。

### 详情页 pages/hanzi/detail?g=<组键>|__all&c=字

- 田字格大字 + 全拼（含 ü 紫色、否则橙，沿用网页端规则）。
- 注音三色分解：声母蓝 #4A90E2 / 介母橙 #FF9500 / 韵母粉 #FF5C8D（与网页端一致），缺省段不显示。
- 多音字提示（组词锁定读音）；笔画数（懒取缓存）；☆ 标记/取消已掌握；上一个 / 下一个在所属范围列表内轮换，显示位置 x / n。

## 入口

- 分类页语文组：原占位「生字卡片」改为「识字卡片」status:'ok'，desc「主题识字 · 注音分解 · 多端同步」，跳识字主页。
- 拼音主页的「拼音识字打卡」占位卡语义不同（300 字打卡），保持占位不动。
